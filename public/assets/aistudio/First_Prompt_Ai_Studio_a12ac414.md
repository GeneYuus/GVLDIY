  - `14px` (`--r-lg`) on the Tactile Porthole Timeline stage, large `Places to Remember` memorial blocks, the floating `Scene Room` dock, and the mobile `More` sheet.
- **iOS Frosted Liquid Glass Materiality**:
  - Render translucent optical glass surfaces (`backdrop-filter: blur(24px) saturate(190%)`, `-webkit-backdrop-filter: blur(24px) saturate(190%)`) paired with laser-thin specular inner top-edge light refraction (`inset 0 1px 0 rgba(255, 255, 255, 0.92)` in light mode; `inset 0 1px 0 rgba(255, 255, 255, 0.16)` in dark mode) and hairline borders (`1px solid rgba(15, 23, 42, 0.09)` light / `rgba(255, 255, 255, 0.11)` dark).
