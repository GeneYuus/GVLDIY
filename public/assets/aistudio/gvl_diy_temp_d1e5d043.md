## 3. Preplanned 3-Iteration Execution Roadmap (Passes 9, 10, and 11)

### Iteration 1 (Pass 9) — Carved Bricolage Inktrap (`90% wdth`) Self-Hosted Typography, Open Header Tracking & Multi-Show Calendar Polish
- **Scope**: `package.json`, `app/layout.tsx`, `app/globals.css`, `ResponsiveArchiveShell.tsx`, `TactilePortholeTimeline.tsx`, `SamplyFlacDeck.tsx`, `DockedLosslessMiniPlayer.tsx`, `MonthFlyerCalendar.tsx`, `ZinePageChrome.tsx`, `lib/puck/puck.config.tsx`, and `components/admin/*`.
- **Deliverables**:
  1. Install and import `@fontsource-variable/bricolage-grotesk/standard.css` (`wdth` + `opsz` + `wght`), `@fontsource-variable/azeret-mono` ([Azeret Mono](https://fontsource.org/fonts/azeret-mono/use)), and `@fontsource-variable/schibsted-grotesk` ([Schibsted Grotesk](https://fonts.google.com/specimen/Schibsted+Grotesk)) in `app/layout.tsx` so genuine carved industrial-flow typography renders immediately under `font-src 'self' data:`.
  2. Lock display headers to `90%` width (`"wdth" 90, "opsz" 42`) and replace negative header `letter-spacing: -0.03em` and JSX `tracking-tight` classes across the entire app with breathable architectural tracking (`0.055em` uppercase `.brand-title`, `0.035em` uppercase `.sec-title`, `0.015em` mixed-case `h3`/`h4` titles at `"wdth" 92, "opsz" 24`, and `0.075em` mono kickers/stamps).
  3. Add the multi-show per-day mechanical switcher in `MonthFlyerCalendar.tsx` when `dayShows.length > 1`.

### Iteration 2 (Pass 10) — Anti-Self-Lockout Auth Fix, Live DB Passphrase Hot-Rotation, Audit CSV/Pagination & API Body Guards
- **Scope**: `lib/dal/auth.ts`, `lib/storage/mysqlRelationalDriver.ts`, `lib/storage/repository.ts`, `app/api/admin/actions/route.ts`, `app/api/webhooks/instagram/route.ts`, `lib/security/publicRequestGuard.ts`, and `components/admin/panels/SubscribersSecurityPanel.tsx`.
- **Deliverables**:
  1. Decouple `global:admin` from 24-hour lockouts in `lib/dal/auth.ts` so bot attacks only lock out the offending `ipHash` while applying a short `30s` burst throttle globally.
  2. Add live MySQL password hash override (`rotate-admin-passphrase` + automatic session revocation) alongside the hPanel `.env` string generator, plus pagination, search filtering, and `.csv` export on `audit_logs`.
  3. Enforce `readBoundedJsonBody` (`32 KB` max) on `POST /api/admin/actions`, `Content-Length` pre-check + non-null object guard on `POST /api/webhooks/instagram`, and MySQL-backed `comment_votes` deduplication.
